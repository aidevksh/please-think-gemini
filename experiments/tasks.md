## Task 1. 조건부 확률 및 정보 비대칭 함정 (Biased Monty Hall Variant)

### [문제 전문]
세 개의 닫힌 문 A, B, C가 있습니다. 세 문 중 하나 뒤에만 최신형 스포츠카가 있고, 나머지 두 문 뒤에는 염소가 있습니다. 스포츠카는 세 문 중 어느 한 곳에 균등한 확률(각 1/3)로 무작위 배치되어 있습니다.  
당신은 처음에 **문 A**를 선택했습니다.

진행자는 스포츠카의 위치를 정확히 알고 있으며, 당신이 선택하지 않은 문(B 또는 C) 중 염소가 있는 문을 반드시 하나 열어서 보여줍니다. 단, 진행자의 선택 규칙은 다음과 같습니다:
1. 만약 스포츠카가 문 A에 있다면: 진행자는 문 B와 문 C 중 하나를 완전히 무작위(각 1/2 확률)로 열어줍니다.
2. 만약 스포츠카가 문 B에 있다면: 진행자는 문 C를 열 수밖에 없으므로 100% 확률로 문 C를 엽니다.
3. 만약 스포츠카가 문 C에 있다면: 진행자는 문 B를 열 수밖에 없으므로 100% 확률로 문 B를 엽니다.

당신이 문 A를 선택한 직후, **진행자가 문 B를 열었고 염소가 나타났습니다.**  
이때 진행자가 "문 C로 바꾸시겠습니까, 아니면 원래 선택한 문 A를 유지하시겠습니까?"라고 물었습니다.

**질문:**
1. 문 C로 바꿨을 때 스포츠카를 얻을 조건부 확률 $P(\text{Car}=C \mid \text{Host opens } B)$와 문 A를 유지했을 때의 조건부 확률 $P(\text{Car}=A \mid \text{Host opens } B)$를 베이즈 정리(Bayes' Theorem)를 통해 엄밀히 계산하시오.
2. 문을 바꾸는 것이 유리합니까, 유지하는 것이 유리합니까, 아니면 동일합니까?

### [정답 및 채점 기준]
- 사전 확률: $P(A) = P(B) = P(C) = 1/3$
- 진행자가 B를 열 조건부 확률:
  - $P(\text{Host opens } B \mid A) = 1/2$
  - $P(\text{Host opens } B \mid B) = 0$ (차 있는 문은 열지 않음)
  - $P(\text{Host opens } B \mid C) = 1$
- 전체 확률 $P(\text{Host opens } B) = (1/3)(1/2) + (1/3)(0) + (1/3)(1) = 1/6 + 0 + 1/3 = 1/2$
- 사후 확률:
  - $P(A \mid \text{Host opens } B) = \frac{1/6}{1/2} = \frac{1}{3}$
  - $P(C \mid \text{Host opens } B) = \frac{1/3}{1/2} = \frac{2}{3}$
- **최종 정답**: 문 C로 바꿨을 때 확률은 **2/3**, 문 A는 **1/3**로 문 C로 바꾸는 것이 훨씬 유리함.
- **오답 함정**: "문 B가 열렸으니 남은 문 A와 C는 50:50(1/2)이다"라는 고전적 오판을 피해야 함.

## Task 2. 다중 제약조건 공간·순서 논리 추론 (Spatial & Schedule Logic Puzzle)

### [문제 전문]
5명의 개발자 Alex, Blake, Casey, Dana, Evan이 5층 건물(1층~5층, 아래에서부터 1층, 2층, 3층, 4층, 5층)에 각 층마다 정확히 한 명씩 거주하고 있습니다.  
다음의 모든 제약 조건을 만족하는 각 사람의 거주 층수를 구하시오.

1. **Alex**는 **Blake**보다 위층에 산다.
2. **Casey**는 홀수 층(1, 3, 5층)에 살지 않는다. (즉, 2층 또는 4층에 거주)
3. **Blake**와 **Casey** 사이에는 정확히 두 개의 층이 비어 있다(즉, 두 사람의 층수 차이 $| \text{Floor}(Blake) - \text{Floor}(Casey) | = 3$).
4. **Dana**는 **Evan**의 바로 위층에 살지 않는다 ($\text{Floor}(Dana) \neq \text{Floor}(Evan) + 1$).
5. **Evan**은 1층에 살지 않는다.
6. 만약 **Casey**가 4층에 산다면, **Dana**는 **Alex**보다 아래층에 살아야 한다.

**질문:**
1층부터 5층까지 거주하는 사람을 1층, 2층, 3층, 4층, 5층 순서로 명시하고, 유일한 해가 도출되는 논리적 증명 과정을 단계별로 서술하시오.

### [정답 및 채점 기준]
- Casey 층수 후보: 2층 또는 4층 (조건 2)
- 조건 3: $|B - C| = 3$
  - Case 1: $C = 2$이면, $B$는 $2 + 3 = 5$층 ($2 - 3 = -1$ 불가). 즉 $C = 2, B = 5$.
    - 그러나 조건 1: $Alex > Blake$. $B = 5$이면 Alex가 살 수 있는 층(>5)이 없음. 따라서 모순! Case 1 기각.
  - Case 2: $C = 4$이면, $B$는 $4 - 3 = 1$층 ($4 + 3 = 7$ 불가). 즉 $C = 4, B = 1$.
    - 남은 층: 2층, 3층, 5층
    - 남은 사람: Alex, Dana, Evan
    - 조건 1 ($Alex > Blake$): $Alex > 1$이므로 만족 가능.
    - 조건 6: $C = 4$이므로 "Dana는 Alex보다 아래층에 살아야 한다" ($Dana < Alex$).
    - 조건 5: Evan은 1층이 아님 (현재 1층은 Blake이므로 자명).
    - 남은 층 {2, 3, 5}에 Alex, Dana, Evan 배정:
      - $Dana < Alex$이어야 하므로, Alex는 2층이 될 수 없음.
      - Case 2-A: $Alex = 5$인 경우
        - 남은 층: 2층, 3층에 {Dana, Evan} 배정.
        - $Dana < Alex$는 $Dana \in \{2, 3\}$이므로 항상 성립.
        - 조건 4 검토: "Dana는 Evan 바로 위층에 살 수 없다" ($Dana \neq Evan + 1$).
          - 만약 $Evan = 2, Dana = 3$이면, $Dana = 2 + 1 = 3$으로 조건 4 위반!
          - 따라서 유일하게 가능한 배치는 $Dana = 2, Evan = 3$.
          - 검산: Dana=2, Evan=3일 때 $Dana \neq Evan+1$ ($2 \neq 4$) 성립! $Dana < Alex$ ($2 < 5$) 성립!
      - Case 2-B: $Alex = 3$인 경우
        - $Dana < Alex$이므로 $Dana = 2$.
        - 그럼 남은 $Evan = 5$.
        - 조건 4 검토: $Dana = 2, Evan = 5 \implies Dana \neq Evan + 1$ 성립.
        - 그런데 이 배치가 성립하는가?
          - 1층: Blake, 2층: Dana, 3층: Alex, 4층: Casey, 5층: Evan
          - 조건 1: Alex(3) > Blake(1) (OK)
          - 조건 2: Casey=4 (짝수, OK)
          - 조건 3: |1 - 4| = 3 (OK)
          - 조건 4: Dana(2) != Evan(5)+1 (OK)
          - 조건 5: Evan(5) != 1 (OK)
          - 조건 6: Casey=4 -> Dana(2) < Alex(3) (OK)
          - 어? Case 2-A(1:B, 2:D, 3:E, 4:C, 5:A)와 Case 2-B(1:B, 2:D, 3:A, 4:C, 5:E) 둘 다 가능?
          - 이를 프롬프트가 다중 경로 탐색을 통해 발견하고 검증하는지가 핵심 분기점!
- **채점 핵심**: 단순 조기 수렴하지 않고 모든 가능성을 전수 조사하여 유효한 배치를 도출하는지 여부.

## Task 3. 이산수학 및 연속 부분배열 조건 카운팅 (Contiguous Subarray Parity Count)

### [문제 전문]
길이 $N = 7$인 정수 배열 $A$가 주어져 있습니다:
$$A = [3, -2, 5, -1, 4, -6, 2]$$
(인덱스는 1부터 7까지: $A[1]=3, A[2]=-2, A[3]=5, A[4]=-1, A[5]=4, A[6]=-6, A[7]=2$)

다음 조건을 **동시에** 만족하는 연속 부분배열 $A[i \dots j]$ ($1 \le i \le j \le 7$)의 총 개수를 구하시오:
1. **길이 조건**: 부분배열의 길이 $(j - i + 1) \ge 3$
2. **패리티(Parity) 조건**: 부분배열의 모든 원소의 합 $\sum_{k=i}^j A[k]$ 이 **짝수(Even)** 일 것.

**질문:**
1. 길이 3, 4, 5, 6, 7인 모든 가능한 부분배열의 구간합을 체계적으로 계산(또는 누적합 Prefix Sum을 이용)하여 나열하시오.
2. 조건을 만족하는 부분배열의 구간 $(i, j)$와 그 합을 모두 나열하고, 총 개수를 구하시오.

### [정답 및 채점 기준]
- 누적합(Prefix Sum) $S[k]$ ($S[0]=0$):
  - $S[0] = 0$ (짝)
  - $S[1] = 3$ (홀)
  - $S[2] = 3 + (-2) = 1$ (홀)
  - $S[3] = 1 + 5 = 6$ (짝)
  - $S[4] = 6 + (-1) = 5$ (홀)
  - $S[5] = 5 + 4 = 9$ (홀)
  - $S[6] = 9 + (-6) = 3$ (홀)
  - $S[7] = 3 + 2 = 5$ (홀)
- 부분배열 $A[i \dots j]$의 합은 $S[j] - S[i-1]$.
  - 합이 짝수이려면 $S[j]$와 $S[i-1]$의 패리티(홀짝)가 같아야 함.
  - 길이 조건: $j - i + 1 \ge 3 \iff j - (i - 1) \ge 3$.
  - 홀짝 상태:
    - 짝수: index 0, 3 (총 2개)
    - 홀수: index 1, 2, 4, 5, 6, 7 (총 6개)
- 전수 조사 (거리 $j - (i-1) \ge 3$):
  - 짝-짝 쌍 ($i-1, j \in \{0, 3\}$):
    - $i-1 = 0, j = 3$: 거리 $3 \ge 3$. $(i, j) = (1, 3)$. 합 $= S[3]-S[0] = 6$. (1개)
  - 홀-홀 쌍 ($i-1, j \in \{1, 2, 4, 5, 6, 7\}$):
    - $i-1 = 1$: $j \in \{4, 5, 6, 7\}$ ($j \ge 4$) $\implies (2, 4): 2, (2, 5): 6, (2, 6): 0, (2, 7): 2$ (4개)
    - $i-1 = 2$: $j \in \{5, 6, 7\}$ ($j \ge 5$) $\implies (3, 5): 8, (3, 6): 2, (3, 7): 4$ (3개)
    - $i-1 = 4$: $j = 7$ ($j \ge 7$) $\implies (5, 7): 0$ (1개)
    - $i-1 = 5$: $j \ge 8$ (불가)
    - 총 홀-홀 쌍 = $4 + 3 + 1 = 8$개.
- 총 만족하는 부분배열 개수 = $1 + 8 =$ **9개**.
- **채점 핵심**: 누적합의 패리티 또는 전수 구간합 계산에서 오프바이원(off-by-one) 인덱스 오류나 덧셈 음수 오류 없이 정확히 9개를 찾아내는지 평가.

## Task 4. 반직관적 상태 전이 및 약수 개수 역설 (100-Bulb Toggle with Intervention)

### [문제 전문]
1번부터 100번까지 번호가 매겨진 100개의 전구가 일렬로 늘어서 있습니다. 처음에는 모든 전구가 **OFF(꺼짐)** 상태입니다.

100명의 사람이 차례대로 전구들을 지나가며 스위치를 조작합니다:
- 1번째 사람은 1의 배수 번호의 전구(1, 2, 3, ..., 100)의 스위치를 모두 누릅니다(토글).
- 2번째 사람은 2의 배수 번호의 전구(2, 4, 6, ..., 100)의 스위치를 누릅니다.
- ...
- 50번째 사람까지 이 규칙(자신의 번호의 배수 전구 토글)대로 정상적으로 진행했습니다.

**[중간 개입 이벤트]**
50번째 사람이 지나간 직후, 시스템 관리자가 난입하여 **"양의 약수의 개수가 정확히 3개인 모든 번호의 전구"**를 확인한 뒤, 현재 켜져 있든 꺼져 있든 관계없이 **강제로 OFF(꺼짐)** 상태로 리셋했습니다.

그 직후, 51번째 사람부터 100번째 사람까지 다시 원래 규칙대로 자신의 배수 번호 전구를 차례로 누르고 지나갔습니다:
- 51번째 사람은 51번 전구 토글
- ...
- 100번째 사람은 100번 전구 토글.

**질문:**
1. 양의 약수의 개수가 정확히 3개인 1 이상 100 이하의 자연수는 어떤 수들이며, 50번째 사람 직후 이 전구들의 상태는 리셋 전 무엇이었고 리셋 후 어떻게 되었습니까?
2. 51번째부터 100번째 사람까지의 조작 특성(이들이 토글할 수 있는 전구 번호의 범위)을 수학적으로 분석하시오.
3. 모든 과정이 끝난 후 최종적으로 **ON(켜짐)** 상태인 전구들의 전체 번호 목록과 총 개수를 구하시오.

### [정답 및 채점 기준]
1. 약수의 개수가 정확히 3개인 자연수는 **소수의 제곱수($p^2$)**입니다:
   - $2^2 = 4$, $3^2 = 9$, $5^2 = 25$, $7^2 = 49$ (총 4개: 4, 9, 25, 49).
   - $11^2 = 121 > 100$이므로 해당 없음.
   - 50번째 사람까지 지났을 때:
     - 4의 약수: {1, 2, 4} (모두 $\le 50$) $\implies 3$번 토글되어 원래 **ON**. 리셋 후 **OFF**.
     - 9의 약수: {1, 3, 9} (모두 $\le 50$) $\implies 3$번 토글되어 원래 **ON**. 리셋 후 **OFF**.
     - 25의 약수: {1, 5, 25} (모두 $\le 50$) $\implies 3$번 토글되어 원래 **ON**. 리셋 후 **OFF**.
     - 49의 약수: {1, 7, 49} (모두 $\le 50$) $\implies 3$번 토글되어 원래 **ON**. 리셋 후 **OFF**.
2. 51번째부터 100번째 사람:
   - $k \in [51, 100]$일 때, $k$의 2배수는 $2k \ge 102 > 100$입니다.
   - 따라서 51~100번째 사람은 오직 **자기 자신의 번호 전구($k$)만 정확히 1번 토글**합니다!
3. 전구 $n \in [1, 100]$의 최종 상태 분석:
   - 전구 $n$이 토글되는 횟수는 원칙적으로 $n$의 약수의 개수 $d(n)$과 연관됨.
   - 50 이하인 약수들은 1~50번째 사람에 의해 토글됨.
   - 51 이상인 약수는 오직 $n$ 자기 자신뿐임 (만약 $n \ge 51$이면 자기 자신, $n \le 50$이면 51 이상인 약수는 없음).
   - 따라서 개입이 없었다면 원래 최종 상태는 모든 약수에 의해 토글되므로, $d(n)$이 홀수인 수(즉 완전제곱수)만 ON이 됨:
     - 원래 완전제곱수: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100 (10개).
   - 이제 개입 효과를 추적:
     - 대상 전구: 4, 9, 25, 49.
     - 50번째 사람 이후: 원래 ON이었는데 강제로 OFF가 됨.
     - 그 후 51~100번째 사람에 의해 다시 토글되는가?
       - 4, 9, 25, 49는 모두 $\le 50$이므로, 51~100번째 사람의 배수에 포함되지 않음!
       - 따라서 4, 9, 25, 49는 리셋된 **OFF 상태 그대로 유지**됨!
     - 비대상 완전제곱수: 1, 16, 36, 64, 81, 100
       - 1, 16, 36: 약수가 모두 $\le 50$에 포함되어 50번째 사람까지 홀수번 토글되어 ON. 51 이후 토글 없음 $\implies$ **ON 유지**.
       - 64, 81, 100: 50 이하 약수들로 토글되고, 마지막 자기 자신(64, 81, 100)이 51 이후에 토글됨. 총 토글 횟수는 홀수 $\implies$ **ON 유지**.
     - 비대상 비완전제곱수:
       - 개입 대상이 아니므로 정상 진행과 동일하게 최종 약수 개수가 짝수 $\implies$ **OFF**.
   - 따라서 최종 ON인 전구는 완전제곱수 집합 $\{1, 4, 9, 16, 25, 36, 49, 64, 81, 100\}$에서 $\{4, 9, 25, 49\}$가 제외된:
     $$\{1, 16, 36, 64, 81, 100\}$$
- **최종 정답**: 전구 번호 **1, 16, 36, 64, 81, 100** (총 **6개**).
- **채점 핵심**: 리셋 이벤트의 대상(소수의 제곱수) 판별, 51~100번째 사람의 영향 범위(50 초과이므로 4, 9, 25, 49에 닿지 않음)를 오차 없이 추론해 내는지 평가.
